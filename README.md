# analisis_datos_ventas_excel
Análisis de Ventas e Identificación de Crecimiento por Área y Producto 
Este proyecto, realizado como primera entrega en el curso de EBAC, se centró en la limpieza, modelado y análisis de datos de ventas para la categoría de 'FABRIC TREATMENT and SANIT'. El objetivo fue transformar datos brutos en información clave para la toma de decisiones, identificando el rendimiento de ventas por región y a lo largo del tiempo, y midiendo las tasas de crecimiento.
